# Maina Eric Kariuki — Portfolio

**Live site:** [mainaericportfolio.vercel.app](https://mainaericportfolio.vercel.app/)

Personal portfolio website for Maina Eric Kariuki, ICT Professional & Web Developer.

## Tech Stack

- **React 18** + **TypeScript**
- **Tailwind CSS** — utility-first styling
- **Vite** — build tool and dev server
- **Lucide React** — icons

## Features

- ✨ Typewriter name animation
- 🌙 Dark / Light mode toggle (persisted)
- 📄 CV viewer (PDF opens in new tab)
- 📬 Contact form with email fallback
- 🗂 Project showcase with category filters
- 🔗 GitHub, LinkedIn, WhatsApp links
- 📱 Fully responsive

## Local Development

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
npm run preview   # preview the build locally
```

## Deployment

Hosted on [Vercel](https://vercel.com). Connect this repository to Vercel and it will auto-deploy on every push to `main`.
